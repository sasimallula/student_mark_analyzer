# Student Marks Analyzer

A Python project to analyze student marks and generate useful results.

## Features

- Accepts student name and registration number
- Accepts subject names and marks
- Calculates total marks
- Calculates average marks
- Finds highest and lowest marks
- Assigns a grade
- Displays Pass/Fail result

## Technologies Used

- Python

## How to Run

1. Download or clone this repository.
2. Open `student_mark_analyzer.py` in VS Code.
3. Run the Python program.
4. Enter the student details and marks when prompted.

## Project Output

The program displays the student's marks details, total, average, highest marks, lowest marks, grade, and result.
